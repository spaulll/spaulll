## `$ whoami`

I'm an engineering student turned trader who still enjoys taking things apart, experimenting with systems, and building tools to solve everyday problems.

I don't build to chase a tech career. I build because something bothers me, an idea sounds interesting, or I want to understand how something works.

These days, AI helps me turn those ideas into working projects.

- ⚙️ **Interests** — Trading systems · Self-hosting · Automation
- 🔄 **Workflow** — Idea → Experiment → Build → Use
- 🎯 **Philosophy** — Solve the problem. Skip the unnecessary complexity.

## `// My approach`

- **Ideas first.** Start with a real problem or something worth exploring.
- **Build pragmatically.** Use whatever tools help turn an idea into a working solution.
- **AI-assisted development.** Treat AI as a tool to accelerate implementation and experimentation.
- **Self-host when it makes sense.** Keep control over my own systems and data.
- **No unnecessary complexity.** A useful personal tool doesn't need to become a startup.
